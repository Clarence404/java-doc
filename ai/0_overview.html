AI 总览

AI 模块从 Java 后端视角讲大模型应用开发：选模型、写 Prompt、工具调用，用 Spring AI / LangChain4j 接入模型，用 RAG 接入私有知识，用 Agent、MCP 编排工具。

版本基线（2026 年 10 月）：JDK 21、Spring Boot 4、Spring AI 2.0、LangChain4j 1.22、MCP 规范 2026-07-28

MCP（Model Context Protocol）由 Anthropic 于 2024 年发起，2025 年 12 月捐赠给 Linux 基金会旗下的 Agentic AI Foundation（AAIF），现由该基金会中立治理；它是协议而不是安全保障，远程 MCP Server 的授权（HTTP 传输按规范走 OAuth）、工具权限与工具输出带来的间接提示注入都要应用自己把关，详见 MCP 协议。

三、推荐阅读路径

  1. 先读基础概念：大模型基础概念 → 大模型选型 → Prompt 工程 → Function Calling（工具调用），后面所有框架和 Agent 都建立在这四篇之上
  2. 选一个框架上手：Spring 技术栈优先 Spring AI，需要声明式 AI 服务或非 Spring 项目看 LangChain4j
  3. 模型接入：开发环境用 Ollama 本地跑，生产对接云端见 API 直接接入
  4. 私有知识问答：Embedding 向量化 → 向量数据库 → RAG 检索增强生成
  5. 复杂任务编排：AI Agent 智能体 → MCP 协议；Prompt 和 RAG 都解决不了时再考虑 模型微调
  6. 最后浏览 AI 编程工具，了解日常开发可用的 AI 工具

复习时用 高频面试题 自测，答案在 AI 面试题解答。

四、关联模块

模型训练和算法原理不在本模块范围内，只讲「把模型当作外部服务，如何稳定、安全、可控地用好它」。版本说明：Spring Boot 3 项目对应 Spring AI 1.1.x，API 大体相同，差异在正文单独标出；LangChain4j 通过 langchain4j-bom 统一版本。模型型号、价格、上下文长度变化很快，正文只写模型家族和选型方法，具体数值以各厂商官方模型页为准。

  • 认证授权、API 安全、权限模型（工具最小权限、MCP 的 OAuth 授权） → 应用安全总览
  • 关键词与向量混合检索（Elasticsearch / OpenSearch） → 搜索数据库
  • 大模型流式输出的传输层（SSE） → SSE（Server-Sent Events）
  • 调用链路、Token 用量与延迟监控 → 可观测性总览
  • 限流、超时、重试、降级等调用外部服务的通用治理 → 高可用总览
  • Spring Boot 自动配置与 Starter 机制 → Spring Boot 总览
