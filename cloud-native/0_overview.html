二、推荐阅读路径

  1. 先读 Linux 概览 与 发行版，打好运维基础。
  2. 再读 Docker 与 Kubernetes，掌握容器化与编排的核心。
  3. 然后读 Nginx 与 Ingress、Helm、Argo CD，形成从打包到持续部署的链路。
  4. 接着读 Terraform 与 Ansible，把基础设施纳入代码管理。
  5. 最后按需阅读云平台与 VPS 相关文档。

三、关联模块
