业务场景总览

业务场景模块以具体业务问题为线索，把缓存、消息队列、数据库、分布式与三高架构的知识组合成完整方案，适合在掌握各技术模块后做综合练习。每篇只写方案的组合方式与关键取舍，涉及的单项技术（限流、热点、分库分表、分布式 ID、事务消息、幂等等）都链接到各自的主文档。

版本基线：示例默认 JDK 21、Spring Boot 4（Spring Data Redis 4）、Redis 8.x、RocketMQ 5.x（rocketmq-spring 2.3.x）、MySQL 8.4 LTS、ShardingSphere 5.5、Flink 2.x；与旧版本行为不同的地方（如 RocketMQ 4.x 的固定延迟级别）在正文中单独标出。

二、推荐阅读路径

  1. 先读 秒杀、订单，这两个场景最能串联三高、缓存、MQ 与分布式事务
  2. 再读 短链接、排行榜和积分、Feed 流和消息推送、搜索，覆盖读多写少、写扩散与检索问题
  3. 交易链路的周边：购物车 → 优惠券和营销 → 支付系统，与订单一起串起从加购、用券、下单到支付对账的完整链路
  4. 实时与高频写：即时通讯、计数系统、扫码登录，覆盖长连接与位点同步、计数合并与热点、跨设备授权
  5. 然后按需阅读 海量数据架构选型、海量数据算法题、海量数据对账、海量数据导入导出、大文件上传、抢红包、附近的人、商品详情页
  6. 幂等是贯穿所有场景的基础能力，统一看 幂等设计
