# LeetCode 高频题分类

**切入点**：先想能不能排序（排序后双指针或二分）；不能改顺序就用 HashMap/前缀和；原地操作多用快慢指针；矩阵题先找规律再模拟。

| 1 | 两数之和 | 🟢 | HashMap |
| 26 | 删除有序数组的重复项 | 🟢 | 快慢指针 |
| 48 | 旋转图像 | 🟡 | 矩阵原地变换 |
| 54 | 螺旋矩阵 | 🟡 | 模拟 |
| 238 | 除自身以外数组的乘积 | 🟡 | 前缀积 |
| 128 | 最长连续序列 | 🟡 | HashSet |
| 560 | 和为 K 的子数组 | 🟡 | 前缀和 + HashMap |

## 九、二分搜索

**切入点**：不只用于有序数组，凡是"答案具有单调性"都能二分（二分答案）；区分左边界（找第一个满足条件）和右边界（找最后一个满足条件）；注意 `mid = lo + (hi - lo) / 2` 防止溢出，循环条件 `lo <= hi` 还是 `lo < hi` 取决于闭/开区间写法。

|------|------|------|------|

| 35 | 搜索插入位置 | 🟢 | 左边界二分 |
| 33 | 搜索旋转排序数组 | 🟡 | 变形二分 |
| 153 | 寻找旋转排序数组中的最小值 | 🟡 | 二分 |
| 34 | 在排序数组中查找元素的第一个和最后一个位置 | 🟡 | 左右边界二分 |
| 4 | 寻找两个正序数组的中位数 | 🔴 | 二分 |

::: tip 刷题建议

3. 刷完一遍后重做错题，直到能在 15 分钟内独立写出
4. 大厂高频：两数之和、LRU、反转链表、三数之和、最大子数组和必须秒杀
:::
