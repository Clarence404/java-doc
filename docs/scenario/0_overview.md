# 业务场景总览

业务场景模块以具体业务问题为线索，把缓存、消息队列、数据库、分布式与三高架构的知识组合成完整方案，适合在掌握各技术模块后做综合练习。

## 二、推荐阅读路径

1. 先读 [秒杀](./4_seckill)、[订单系统](./5_order_system)，这是最能串联三高、缓存、MQ、分布式事务的两个综合场景。
2. 再读 [短链接](./6_shorturl)、[排行榜](./7_rank_system)、[Feed 流](./8_feed_stream)、[搜索系统](./9_search_system)，覆盖常见的读多写少与写扩散问题。
3. 然后按需阅读 [文件上传](./10_file_upload)、[抢红包](./11_red_packet)、[附近的人](./12_geo_nearby)、[幂等设计](./13_idempotent)。
4. 准备面试时结合 [项目亮点与难点](./3_work_star) 与 [常见场景问题](./1_scene) 复习。
