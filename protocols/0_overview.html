网络协议总览

网络协议模块从 Java 后端视角讲协议：重点是 TCP、HTTP、TLS、DNS 与 RPC，数据库、邮件、文件等外围协议只讲对接所需的报文流程与安全要点。

版本基线（2026 年 10 月）：JDK 21、Spring Boot 4、Linux 内核 5.x / 6.x

一、模块导航

文档覆盖内容
TCP 与 UDP三次握手、四次挥手、TIME_WAIT / CLOSE_WAIT、滑动窗口、拥塞控制、keepalive、UDP
HTTP方法与状态码、缓存、Cookie 与会话、长连接、HTTP/2、HTTP/3 与 QUIC、HttpClient
HTTPS 与 TLSTLS 1.3 握手、前向保密、证书链校验、SNI / ALPN / HSTS、mTLS、SSL Bundle
DNS域名层级、递归与迭代、记录类型、TTL 与缓存、DoH / DoT、DNS 负载均衡、ndots、JVM DNS 缓存
RPC 协议RPC 组成要素、Protobuf 编码、gRPC 帧格式与四种调用、截止时间与状态码、Thrift、SOAP
数据库协议JDBC 分层、MySQL 握手与认证、PostgreSQL 消息格式、Redis RESP2 / RESP3
邮件协议SMTP 与端口、IMAP / POP3、MIME 结构与编码、SPF / DKIM / DMARC、Spring 发信

二、推荐阅读路径

  1. 先读 TCP 与 UDP，握手挥手、TIME_WAIT、拥塞控制是后面所有协议的底座
  2. 再读 HTTP 和 HTTPS 与 TLS，覆盖 HTTP/1.1 → HTTP/2 → HTTP/3 的演进、缓存与 TLS 1.3 握手、证书链
  3. 然后读 DNS，理解域名解析、TTL 与缓存对服务发现和故障切换的影响
  4. 服务间调用读 RPC 协议，gRPC 的帧格式、截止时间、状态码与长连接负载均衡
  5. 外围协议按需阅读：数据库协议（连接认证类报错时查）、邮件协议（发系统通知时查）、文件协议（与外部系统做文件交换时查）

高频面试题 只列题目，答案在 网络协议面试题解答。

三、协议选型速查

场景推荐原因
对外开放 APIHTTP + JSON生态最广、易调试，规范见 API 设计规范
服务间高性能调用gRPC 或 Dubbo 3 TripleHTTP/2 + Protobuf，强类型契约，支持流式；选型见 服务通信
服务端向浏览器单向推送SSE基于普通 HTTP，自动重连，见 SSE（Server-Sent Events）
浏览器双向实时通信WebSocket全双工、低开销，见 WebSocket
传输加密TLS 1.31-RTT 握手，只保留前向安全的密钥交换
弱网、移动端、连接迁移HTTP/3（QUIC）基于 UDP，消除 TCP 层队头阻塞，切换网络不断连
系统通知邮件SMTP 587 / 465 + SPF、DKIM、DMARC缺少发信认证会被当作垃圾邮件
与外部系统交换文件SFTP单端口、SSH 加密、公钥认证

四、关联模块

IO 模型、Netty 编程、WebSocket、SSE 等「怎么写网络程序」的内容放在 Netty 模块，认证授权放在应用安全模块，本模块只讲协议本身。协议以现行 RFC 为准（TCP RFC 9293、HTTP 语义 RFC 9110、HTTP/2 RFC 9113、HTTP/3 RFC 9114、TLS 1.3 RFC 8446），与旧版本行为不同的地方在正文中单独标出。

  • IO 模型、Reactor、Netty 编程、粘包拆包、心跳、WebSocket、SSE → Netty 总览
  • 网络层面的性能优化（零拷贝、连接复用、压缩、序列化选择） → IO 与网络优化
  • JWT、OAuth2、mTLS 在服务网格中的使用、零信任 → 应用安全总览
  • MQTT、CoAP、Modbus 等物联网协议 → 通信协议
  • Raft、Paxos、ZAB、Gossip 等一致性与集群协议 → 分布式理论
  • AMQP 与消息队列协议 → RabbitMQ
  • 服务间调用方式选型、Dubbo → 服务通信 / Dubbo
