数据库总览

数据库模块整理 Java 后端常用的数据存储知识：以 MySQL 为主线讲清索引、事务与锁、执行流程、InnoDB 与复制，再对比 PostgreSQL，然后覆盖国产与分布式关系库、ORM、各类 NoSQL，最后落到 CDC、备份恢复、分库分表、连接池与 JDBC 驱动等工程实践。缓存、系统级的分库分表策略、分布式事务和 Spring 数据访问在各自模块展开，这里只讲数据库本身。

版本基线：MySQL 8.4 LTS 为主，文中单独标出与 9.7 LTS（2026 年 4 月 GA，之后的版本改用 YY.M 日历版本号，如 26.7）及 8.0（2026 年 4 月随 8.0.46 停止维护）的差异；PostgreSQL 18（兼顾 17）；MariaDB 以 12.3 / 11.8 LTS 为准；Connector/J 9.x、HikariCP 7.x、ShardingSphere 5.5.x；Debezium 3.x 运行在 Kafka 4（KRaft）上。

三、推荐阅读路径

  1. MySQL 基础：范式、视图、存储过程、账号与传输安全，以及 MySQL 核心专项的导读
  2. MySQL 索引 和 MySQL 事务与锁：补齐最高频的性能与并发问题，再按需读执行流程、EXPLAIN、InnoDB 与复制
  3. MySQL 版本特性 与 MySQL 避坑指南：确认生产版本的行为差异和常见雷区
  4. PostgreSQL 基础：对比 PostgreSQL 与 MySQL 在类型系统、MVCC、索引和高级 SQL 上的差异
  5. 单机到瓶颈时读 分布式数据库（TiDB / OceanBase）；分析、时序、文档、搜索等场景从 列式与 OLAP 数据库 开始按需选读
  6. 工程落地读 CDC 工具、数据备份与恢复、分库分表与中间件、数据库连接池 和 MySQL JDBC 驱动
  7. 做技术决策时看 数据库选型参考

四、选型原则

问题优先判断
需要强事务与复杂关联查询MySQL / PostgreSQL 等关系型数据库
全文检索、多条件组合搜索Elasticsearch / OpenSearch，数据以关系库为准、异步同步
单机容量或写入到瓶颈先读写分离与分库分表，再评估 TiDB、OceanBase；系统级扩展策略见 数据层扩展
以时间序列写入与聚合为核心InfluxDB 3、TDengine、TimescaleDB 等时序数据库；监控指标存储用 Prometheus
大规模聚合分析ClickHouse、Apache Doris、StarRocks 等列式 OLAP
文档结构变化频繁MongoDB 等文档数据库

工程上的几条底线：

  • 业务早期保持模型简单，不要过早引入分库分表和多种异构数据库
  • 上生产前明确 RPO / RTO、备份与恢复演练、慢 SQL 治理、连接池上限和索引变更流程
  • 跨库一致性优先用本地事务 + Outbox、Saga、幂等来解决，详见 分布式事务
