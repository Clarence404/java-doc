实战手册总览

实战手册把散落在各模块里的排查命令和线上故障收拢成一本随手可翻的工具书：速查表只给能直接复制的命令，故障案例按「现象、排查、根因、修复、预防」复盘真实问题。原理一律链接到对应模块的主文档，这里不重复展开。

版本基线（2026 年 10 月）：JDK 21 / 25、Spring Boot 4、MySQL 8.4、Redis 8、Kafka 4、Kubernetes 1.37、Arthas 4

二、推荐阅读路径

本模块分两部分，用法不同：

  • 速查表：日常开发和值班时按场景查命令，表格固定为「场景 | 命令 | 说明」，复制后把 <pid>、<pod> 等占位符换成实际值即可
    1. Linux 排查命令速查：负载、内存、磁盘、网络、进程、日志与 Java 进程
    2. Git 命令速查：日常提交、分支同步、整理历史、撤销与找回、定位问题
    3. Docker 与 kubectl 速查：容器与 Pod 的状态、日志、进入、发布回滚、资源与网络
    4. Arthas 速查：附着、全局概览、方法级观察、类加载器、热修复与收尾
    5. JVM 参数与 GC 日志速查：堆与容器参数、GC 选择、GC 日志与运行时查看
    6. MySQL 排查速查：慢查询、执行计划、连接、锁等待、死锁与复制状态
    7. Redis 运维命令速查：大 Key / 热 Key、延迟、内存淘汰、慢日志与集群
  • 故障案例：用于故障演练和面试准备，先只看「现象」自己推一遍排查思路，再对照后面的排查过程和根因；每个案例的处置命令都能在速查表里找到

建议的节奏：先把速查表各过一遍，知道每类问题该用哪个命令；再按故障案例做演练，遇到不熟的原理顺着文中链接回到主文档补齐。

复习时用 高频面试题 自测，答案在 实战手册面试题解答。

三、关联模块

  • Linux 基础、systemd、信号与 fd 上限 → Linux 概览；USE 排查方法 → 性能分析方法论

  • 镜像构建与容器原理 → Docker；探针、滚动发布与常见 Pod 故障 → Kubernetes
  • JDK 自带诊断工具 → 诊断工具；OOM、CPU 飙高、死锁的排查流程 → 故障排查
  • Arthas 原理、容器附着与安全守则 → 线上诊断
  • 慢 SQL 与执行计划 → EXPLAIN 与 SQL 优化；Redis 生产问题 → Redis 实战；消息堆积与重复消费 → 消息队列基础
