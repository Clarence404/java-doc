Spring 总览

Spring Framework 是 Java 后端的基础框架：IoC 容器负责创建与装配对象，AOP 把事务、缓存、权限等横切逻辑从业务代码中剥离，在此之上提供 Web（Spring MVC / WebFlux）、事务、数据访问等能力。本模块讲 Framework 本身的机制与常用组件，以及 Spring Security、Spring Batch、Spring Integration 等周边项目；Spring Boot 的自动配置与工程化放在 Spring Boot 模块，微服务组件放在 Spring Cloud 模块。

版本基线：Spring Framework 7.x / Spring Boot 4.x / Spring Security 7 / JDK 17+（推荐 21 / 25），与 Framework 6.x / Boot 3.x 行为不同的地方在文中单独标出。

二、推荐阅读路径

按侧边栏分组顺序阅读，每篇末尾的「下一篇」串起整条链路。

核心容器（1–4）

  1. IoC 容器：refresh 流程、依赖注入、Bean 定义来源、作用域、生命周期、扩展点与循环依赖
  2. AOP：通知类型与执行顺序、切点表达式、代理选择、自调用失效
  3. MVC：DispatcherServlet 流程、参数解析与校验、消息转换、ProblemDetail 异常处理、API 版本
  4. 事务管理：@Transactional 原理、传播行为、回滚规则、编程式事务与失效场景

常用组件（5–8）

  1. Cache 抽象：缓存注解、CacheManager、Redis 序列化与常见陷阱
  2. Retry 重试：退避策略与熔断，Framework 7 内置弹性注解
  3. 事件机制：同步 / 异步事件、事务事件与事件驱动解耦
  4. WebFlux：Reactor、背压、WebClient 与 R2DBC

安全（9–11）

  1. Spring Security：过滤器链、JWT、方法级与动态权限
  2. 安全框架对比：Spring Security、Shiro、Sa-Token 的取舍
  3. Spring SSO 接入：LDAP、CAS、SAML2、OIDC、Keycloak、自建授权服务器

批处理与集成（12–13）

  1. Spring Batch 批处理：Job / Step、分块读写与重启
  2. Spring Integration：消息通道、集成 DSL 与 Camel 对比

题目清单（99）：高频面试题，答案见 Spring 面试题解答。

三、关联模块

  • Spring Boot：自动配置、Starter、配置体系、测试与启动优化；版本差异见 Spring Boot 版本演进
  • Spring Cloud：注册发现、网关、服务调用、配置中心与治理
  • Java · 动态代理：JDK 代理与 CGLIB 的实现细节，AOP 与事务的底层
  • Java · 虚拟线程：Framework 6.1 / Boot 3.2 起的虚拟线程支持
  • 数据库 · MySQL 事务与锁：隔离级别、MVCC 与锁，事务管理的数据库侧
  • 应用安全：JWT、OAuth2、OIDC、SSO 的协议原理
  • Spring 面试题解答：本模块高频问题的答案汇总

2、版本演进

版本发布关键变化
5.x2017JDK 8+；WebFlux 响应式栈；Kotlin 支持；5.3 为最后一个 javax 版本（对应 Boot 2.x）
6.02022.11JDK 17+；javax.* → jakarta.*（Jakarta EE 9+）；AOT 与 GraalVM 原生镜像；HTTP Interface；ProblemDetail（RFC 7807 / 9457）；非 public 方法可被 CGLIB 代理事务化（对应 Boot 3.0）
6.12023.11虚拟线程支持（虚拟线程）；RestClient、JdbcClient；MVC 内置方法参数校验；CRaC 检查点（对应 Boot 3.2）
6.22024.11Bean 后台初始化；@MockitoBean / @MockitoSpyBean；@EnableTransactionManagement(rollbackOn = ALL_EXCEPTIONS)；单例锁机制重构（对应 Boot 3.4 / 3.5）
7.02025.11Jakarta EE 11（Servlet 6.1）；JSpecify 空安全注解；默认 Jackson 3（Jackson 2 支持废弃）；MVC / WebFlux 内置 API 版本控制；@Retryable / @ConcurrencyLimit 内置弹性注解；@ImportHttpServices 注册 HTTP 服务客户端；HttpMessageConverters 构建器（对应 Boot 4.0）
7.12026RestTemplate 标记废弃，推荐 RestClient（对应 Boot 4.1）

Spring Boot 各版本的升级清单与支持周期见 Spring Boot 版本演进。
