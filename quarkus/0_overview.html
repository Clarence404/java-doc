Quarkus 总览

Quarkus 是 Red Hat 主导的云原生 Java 框架，把 Spring Boot 在运行期做的扫描、代理生成和 Bean 装配挪到构建期，启动更快、内存更低。本模块从构建期增强讲到 REST、数据访问、原生镜像、响应式，以及迁移与框架对比。

版本基线（2026 年 10 月）：Quarkus 3.40 LTS、JDK 21 / 25、Mandrel / GraalVM 25

一、学习路线

GraalVM 的通用原理、虚拟线程和 Reactor 在各自模块展开，这里只讲 Quarkus 特有的部分。版本说明：3.40 LTS 维护到 2027-09-30，Quarkus 3 的 JVM 模式支持 JDK 17–25。Quarkus 4.0 已于 2026-10-01 发布 Beta1，最低要求 Java 21，并升级到 Vert.x 5、Jackson 3 和 Hibernate ORM 8，计划 11 月底 GA；本模块以 3.40 LTS 为准，Quarkus 4 的变化在文中单独标出。

三、阅读建议

  • 第一次接触 Quarkus：按顺序读完前两篇。Quarkus 概览 讲的构建期增强，是理解后面所有特性和限制的前提。
  • 从 Spring Boot 转过来：读完 Quarkus 概览 后直接读 从 Spring Boot 迁移 的概念对照，再回头读第 2～4 篇。
  • 关注启动速度与资源占用：重点读 原生镜像与云原生部署，并对照 启动与部署优化 中 Spring Boot 的 CDS、AOT 缓存与原生方案。
  • 做框架选型：看 其他 Java 框架 的选型对比，以及 Vert.x 概览 中 Vert.x 的定位。

复习时用 高频面试题 自测，答案在 Quarkus 面试题解答。

四、关联模块

  • Vert.x 总览：Quarkus 的 HTTP 层、事件总线和响应式客户端都跑在 Vert.x 之上
  • 启动与部署优化：Spring Boot 的启动优化与原生方案，可与 Quarkus 的做法对照；Spring Boot 本身见 Spring Boot 总览
  • JIT 编译：GraalVM Native Image 的静态分析、闭世界假设与 AOT 编译原理
  • WebFlux：Reactor 的执行模型与背压，可与 Mutiny 对照
  • 虚拟线程：@RunOnVirtualThread 的基础，钉住与 ThreadLocal 的坑
  • Kafka：Kafka 本身的可靠性配置、幂等消费与 Exactly-Once
  • Kubernetes：Kubernetes 扩展生成的部署清单与健康探针，更多内容见 云原生总览
  • 指标监控 / OpenTelemetry：Micrometer 指标与链路追踪，更多内容见 可观测性总览
