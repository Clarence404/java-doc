Java 总览

本模块覆盖 Java 语言本身：语言机制（异常、字符串、枚举、内部类、泛型、反射、代理）、IO 与数据（时间、IO / NIO、序列化、SPI、集合）、并发编程（JMM、线程、锁、原子类、同步工具、线程池、CompletableFuture、虚拟线程）以及各版本新特性。JVM 内部原理与 Spring 等框架在各自模块展开，这里只在需要时一句话带过并给出链接。

版本基线：JDK 21 / 25 LTS，与 JDK 8 / 17 行为不同的地方在文中单独标出。

二、推荐阅读路径

按侧边栏分组顺序阅读，每篇末尾的「下一篇」串起整条链路。

综合（1–2）

  1. Lambda、Stream 与注解：Lambda 的 invokedynamic 实现、Stream 求值模型与并行流、Optional 规范、注解处理器
  2. 版本演进：JDK 8 到 27 的关键特性、预览到正式的路线、升级坑点与版本选型

语言机制（10–16）

  1. 异常体系：受检与非受检异常的设计与生产中的处理规范
  2. String：不可变性、常量池、拼接的编译优化
  3. 枚举：枚举的本质、常用模式与枚举单例
  4. 内部类：静态嵌套类、内部类、局部类与匿名类
  5. 泛型：类型擦除、通配符与 PECS
  6. 反射：Class 对象、反射调用、MethodHandle 与模块封装
  7. 动态代理：JDK 代理与 CGLIB / ByteBuddy

IO 与数据（17–21）

  1. 日期与时间：java.time 体系与时区处理
  2. IO 与 NIO：流体系、Buffer / Channel / Selector、零拷贝
  3. 序列化：JDK 序列化机制、风险与替代方案
  4. SPI 机制：ServiceLoader 与 JDBC / Spring Boot / Dubbo 的扩展机制
  5. 集合框架：HashMap、ConcurrentHashMap 等核心集合的实现

并发（22–30）

  1. JMM 内存模型：可见性、有序性、happens-before 与 volatile
  2. 线程基础：线程状态、中断、ThreadLocal
  3. synchronized：对象头、锁状态与 JDK 15 / 23 之后的变化
  4. 显式锁（Lock）：AQS、ReentrantLock、读写锁
  5. 原子类（Atomic）：CAS、ABA、LongAdder
  6. 同步工具类：CountDownLatch、CyclicBarrier、Semaphore 等
  7. 线程池：ThreadPoolExecutor 参数、拒绝策略与生产配置
  8. CompletableFuture：异步编排与线程池选择
  9. 虚拟线程：调度模型、pinning 与使用边界

附录（98）

  1. 效率工具库：Lombok、MapStruct、Hutool、Guava 的用法、坑点与 JDK 内置替代
